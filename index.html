BarokeShorts

Manage your own YouTube channels from one place.

BarokeShorts is a single-user desktop application that a creator runs on their own computer to manage multiple YouTube channels they own: uploading short-form videos, reviewing channel and video statistics, and updating a video's privacy status.

What the application does

The application helps an individual creator operate the YouTube channels they own from a single dashboard. It runs entirely on the user's own computer — there is no shared server, and it is used only by its owner to manage channels they own and have authorized.

Connect

Signs in with Google OAuth 2.0. Granted scopes are stored locally and used only for the user's own channels.

Upload

Uploads short-form videos to the user's own channels, with optional title, description, and scheduled publish time.

Analyze

Reads the user's own channel statistics (subscribers, views) and video list to show a performance dashboard.

Manage

Switches a video between public and private, or removes a video the user uploaded, when content needs to be hidden or restored.

How the application uses YouTube data

The application requests the following Google OAuth scopes. Each is used only to provide a feature to the user for channels the user owns.

ScopeWhy the application needs it
youtube.upload To upload short-form videos to the user's own YouTube channels. This is the core purpose of the application.
youtube.readonly To read the user's own channel statistics (subscribers, views) and list of uploaded videos, so the user can review performance inside the application.
youtube.force-ssl To change the privacy status of the user's own videos (public ↔ private) and to delete a video the user uploaded. YouTube requires this scope for any video update or delete operation.

Data handling & privacy

Runs locally   No third-party sharing   Single user

  • The application runs on the user's own computer. There is no hosted backend that collects or stores user data.
  • OAuth tokens are stored only in a local file on the user's machine and are used solely to call the YouTube Data API on the user's behalf.
  • YouTube data accessed by the application is never sold, and is never shared with any third party.
  • The application accesses only channels that the user owns and has authorized.
